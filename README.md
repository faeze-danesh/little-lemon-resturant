# 🍋 Little Lemon Restaurant App

A responsive and modern restaurant web application built as part of the **Meta Front-End Developer Capstone Project** on Coursera.

## 🚀 Live Demo

👉 [View Live Site](https://little-lemon-resturant-five.vercel.app)

## 📸 Project Overview

This project is a single-page application for the Little Lemon restaurant, allowing users to:

- View restaurant homepage
- Explore menu and specials
- Make a table reservation
- Submit customer details
- Receive reservation confirmation

## 🛠️ Built With

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router
- API integration

## 📌 Features

- Responsive design for mobile and desktop
- Interactive reservation form
- Form validation for user input
- Multi-page navigation using React Router
- Clean UI based on design guidelines

## 🎯 Project Purpose

This project was built to demonstrate front-end development skills including:

- Component-based architecture
- State management
- Form handling
- UI/UX design principles
- Real-world project structuring
